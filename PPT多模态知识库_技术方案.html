一、系统总览

本系统把一份教学 PPT 自动转化为可检索、可复用、可再加工的多模态教学知识库：文本、公式、图片及其语义理解被按页对齐，并由大模型进一步加工为教材文案，最终产出「图片集 + 图片理解 + 教材文案 + 图文绑定 JSON」四类资产，可一键导出为教材 HTML 或教学 Deck。

（教材角度解读） <名>_textbook.md 教材文案

（每页文案 ↔ 该页图片） ⑥ 一键成书 gen_html / build_deck ⑦ 编排执行 PPT-Paser ⑧ 知识库应用（RAG / 个性化 / 出题）
图 1 · 系统总体架构：提取层 → 模型加工层 → 资产层 → 应用层

提取层

本地解析 PPT 包内 XML/OLE/媒体，不依赖网络，产出结构化中间文件（过程文件/）。

模型层

视觉模型理解图片、文本模型撰写教材文案，全部带页码对齐上下文。

资产层

四类有效结果（图片/图片理解/教材文案/图文绑定）进入结果目录，供下游任意消费。

应用层

教材 HTML/教学 Deck/知识问答/个性化学习/试题生成，见第五节案例。

三、各指令技术方案

① 图片提取与过滤 cli_img Pillowultralytics/YOLOpywin32PowerPoint COM

  • 对象识别：解析 slide XML，按 <p:pic>、形状填充、背景链（页→版式→母版）、OLE 公式、图表五类对象提取媒体，裁剪 srcRect 并按形状位置标注坐标（xfrm off → px）。
  • 三路过滤：规则层（尺寸过小 / 宽高比过限 / 纯色 / 孤立字符）→ 位图封装 WMF 判据（解析 WMF 记录流：内嵌位图且无曲线记录 = 公式矢量版，直接滤除）→ YOLO 教学判据（本地权重，未检出的教学图强保留）。
  • 方案 B 矢量处理：位图封装 WMF（公式版）由 PowerPoint COM 渲染为高清 PNG → 视觉模型识别为 LaTeX 追加进 formulas.md；曲线型 WMF（真电路图/波形图）渲染为 PNG 收录进 images/。
  • 运行明细：逐页打印每张图的文件名 / 类型 / 尺寸 / 位置 / 形状。

② 公式提取 cli_formula omml2latexolefilepix2texLibreOffice

三路径级联，全部转为 LaTeX：

路径来源实现覆盖场景
路径 1原生 OMML（<m:oMath>）omml2latex 库转换PowerPoint 2013+ 原生公式
路径 2Equation.3 OLEolefile 解包 + 内置 MTEF 解码器公式编辑器（MathType）对象
路径 3其余公式LibreOffice 渲染 + xfrm 裁剪 + 数学 OCR图片/特殊封装公式

符号判据过滤误识别碎片；运行中逐条打印来源与 LaTeX 片段。

③ 文本提取 cli_text ElementTree

逐页遍历文本框 / 表格 / 标题占位符，排除页眉、页脚、页码与母版固定文本；输出 ID | 类型 | 文本 清单，标题条目被后续用于 HTML 章节命名。

④ 图片 AI 解读 cli_caption qwen3.7-plusDASHSCOPE

  • 文档上下文模式：先从文本前 3~5 页让模型判断课程/专业名（填入提示词括号），每张图附带该页文本+公式上下文再喂入视觉模型，从教材角度输出 100~200 字理解（图片类型 / 内容理解 / 教学用途）。
  • 工程保障：损坏图预检跳过（不浪费 Token）、失败自动重试、增量落盘（中断不丢已解读结果）。

⑤ 教材文案生成 cli_author deepseek-v4-flashDEEPSEEK_API_KEY

  • 学科推断：texts 前 3~5 页交模型判断，填入「教材建设专家 + 多模态知识库工程师 + {学科}专业资深教师」提示词。
  • 整文一次生成：文本/公式/图片理解三份文档全文输入，系统提示词约束「不遗漏任何一页、任何公式」→ 系统性优于逐页调用。
  • 自适应分批：单批受三重约束（输入字符 / 页数 / 估算输出），超限自动拆批并合并到同一 md，防截断并告警。

⑥ 图文绑定 cli_bind

把每页文案与该页图片及解读绑定为 JSON（按页组织 {page, text, images[{file, caption}], has_image}），作为检索与知识图谱的基石。

⑦ 整体编排 PPT-Paser 环境自愈Key 引导Token 预估执行汇报

环节能力
组件自检7 项 pip 依赖缺失自动安装；YOLO 权重缺失自动下载提示；LibreOffice 可选探测
Key 引导两个 Key（DeepSeek / 百炼）缺失时打印注册网页、用途、资费，交互输入并 setx 写入，提示重启后重跑
计划确认分步说明每步干什么；图片解读/教材文案给出 Token 量级与耗时估算；输入 y 才执行（接受费用）
执行汇报完成后输出每步工作量统计 + 结果文档使用说明

⑧ 成果导出 gen_html / build_deck

gen_html.py：binding.json + images → 单文件教材 HTML（MathJax 公式渲染、图注、目录、PPT 原生标题）；build_deck.py：基于 Lieflat edu-blueprint 风格生成 14 张横版教学 Deck（左脊导航 + 顶部选项卡 + 图卡 + 完整正文）。

四、关键技术要点

页码对齐

文本/公式按 ## 第 N 页 分块，图片从文件名 slide_NN 提取页码，三源在页面级天然对齐。

无信息损失

公式图片（WMF 位图封装）经 PowerPoint 渲染 + 视觉识别补回 LaTeX，避免过滤丢内容。

零回归设计

各指令协议稳定、薄壳式架构；渲染/识别等增强为后置钩子，失败自动降级。

增量与断点

解读增量落盘、编排 --skip 断点续跑、批次合并防截断。

成本透明

执行前 Token 估算与确认；公式识别可切本地 pix2tex（零费用）。

可溯源

过程文件全保留（by_page / manifest / 过滤报告 / 提取文档），可审计可复跑。

五、多模态知识库怎么用：应用场景与案例

案例 1 · 自动构建「课程知识内容体系」

需求：项目/新课建设时，需要把散落课件整理为规范的知识体系（章→节→知识点→配图→公式）。

做法：对全部章节课件跑 PPT-Paser → 得到按页组织的教材文案与图文绑定 → 以 binding.json 为骨架，按章节聚合生成知识树：每节 = 教材文案，每个知识点 = 对应公式（LaTeX）+ 配图（PNG）+ 图片解读。

产出：可直接用于课程大纲、教学资源包、知识图谱的种子数据。教材 HTML 即知识体系的「人读版」。

案例 2 · 基于学情测验的「个性化学习内容生成」

需求：学生测验答题后，系统按错题知识点推送针对性讲解。

做法：测验题目标注知识点标签 → 标签在 binding.json / textbook.md 中检索对应章节文案、公式与图片 → 大模型把「标准教材文案 + 学生错题 + 学情画像」融合，生成个性化讲解（含配图、公式、难度调整的例题与变式练习）。

效果：同样的知识库，千人千面——基础薄弱者得到概念重构版，进阶者得到工程扩展版。

案例 3 · 教材二次开发与多形态出版

以 textbook.md 为内容源，可按新大纲重新组织章节（增删、并页、重排序）；可一键导出教材 HTML（网页阅读/打印）、教学 Deck（课堂讲授）、可继续转 Word/PDF。图片与公式均为独立资产，支持双语、无障碍（图注可读）等再加工。

案例 4 · 智能问答与 RAG 检索

binding.json 天然是结构化检索索引：问题 → 检索相关页文案 → 命中页的图片、公式、解读一并返回，构成图文并茂的答案（而非纯文本）。可接入向量库做语义检索，也可用关键词 + 页码做轻量检索，答案自动附「该知识点在第 X 页、见下图」。

案例 5 · 试题与测验生成

基于每页文案与公式，按 Bloom 认知层次（识记/理解/应用/分析）自动生成：概念选择题（选项干扰项来自同节近似概念）、计算题（由公式 LaTeX 生成参数变体）、电路分析题（以真实配图为题干）。

案例 6 · 教师备课与教学竞赛

教师输入新课件 → 几分钟拿到：教材文案（备课讲义）、图片理解（配图说明）、教育蓝图风 Deck（课堂演示 / 教学竞赛申报），从「找图、写稿、排版」中解放出来，聚焦教学设计本身。

六、快速上手

# 1. 一条命令跑完整流水线（自动装依赖 / 引导 Key / 预估 Token / 确认执行）
python cli_paser.py 第九章功率放大电路.pptx -o output

# 2. 结果目录内：
#    images/ + <名>_captions.md + <名>_textbook.md + <名>_binding.json

# 3. 导出教材 HTML（MathJax 公式渲染，PPT 原生标题章节）
python gen_html.py output -o output/第九章.html

# 4. 导出教学 Deck（edu-blueprint 风格，14 张横版滑片）
python build_deck.py   # 生成 9-功率放大电路_deck_full.html

# 5. 单步执行与断点续跑
python cli_img.py 课件.pptx -o out          # 只看图片
python cli_caption.py out/images -o cap.md  # 只做图片解读
python cli_paser.py 课件.pptx -o out --skip img,formula,text   # 从解读开始续跑
