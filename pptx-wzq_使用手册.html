零、关于本工具与作者

作者：吴振谦 · wuzhenqian@nbu.edu.cn · QQ：38328063

开发原因：高校教师在课程建设与教材建设中，长期面临「课件里的大量图片、公式、文本散落各处，难以整理为规范、可复用、图文并茂的教学资源」的痛点——手工整理一份课程的图文知识库往往要耗费数周。作者开发本工具，目的就是把 PPT 自动转化为图文并茂的多模态教学知识库，让教师从机械的整理工作中解放出来，把精力聚焦到教学设计本身。

开发时间与周期：本项目历经需求分析、核心提取引擎开发、AI 加工链路（图片理解/教材文案）、整体编排与打包发布等阶段，从初版原型到 v1.0.0 可安装发行版，累计开发周期约 1 个月（持续迭代中）。

后续开发计划：① 在现有 PPT 知识库基础上，新增微课视频分析能力——自动提取视频中的讲解音频（语音转写）、画面关键帧与字幕时间轴，与 PPT 页面/知识点对齐，形成「音视频 + 图文」融合的多模态知识库构建工具；② 支持更多输入格式（PDF/Word 讲义）；③ 提供图形界面与 Web 服务化部署。

一、它能做什么（工作流程总览）

输入一份教学 PPT（.pptx），自动完成 6 步流水线：

1
图片提取+过滤：识别全部图片/背景/填充，按教学判据去噪，矢量图（WMF）识别与 PowerPoint 渲染
2
公式提取：OMML / 公式编辑器 / OCR 三路径 → LaTeX 公式文档
3
文本提取：逐页文本框/表格/标题，排除页眉页脚
4
图片 AI 解读：每张图结合该页文本/公式，从教材角度解读（消耗 Token）
5
教材文案：DeepSeek 大模型生成每页 300 字以上教材口吻文案（消耗 Token）
6
图文绑定：每页文案与该页图片关系绑定为 JSON；并可一键导出教材 HTML / 教学 Deck

二、环境要求与下载

系统要求

  • Windows 10/11（强烈建议；矢量渲染依赖本机 PowerPoint 与 pywin32）
  • Python 3.9 及以上（官网下载：python.org → Downloads → Windows installer，安装时勾选 "Add Python to PATH"）
  • 建议已安装 Microsoft Office PowerPoint（用于矢量图 WMF 渲染，缺失时自动降级）

下载方式

  1. GitHub 下载源码：访问 https://github.com/<你的用户名>/pptx-wzq → Code → Download ZIP，解压到本地；
  2. 或 pip 安装发行版（发布到 PyPI 后）：pip install pptx-wzq

三、安装

# 方式 A：从源码安装（推荐开发者）
cd pptx-wzq
pip install -e .

# 方式 B：附带本地公式 OCR 组件（可选，零费用识别）
pip install -e ".[ocr]"

# 查看是否安装成功（9 个命令均可使用）
pptx-img --version
pptx-paser --version

安装时会自动拉取依赖：Pillow（图像处理）、openai（大模型接口）、olefile（公式 OLE 解包）、ultralytics（YOLO 图片过滤）、omml2latex（公式转 LaTeX）、pywin32（Windows 矢量渲染）。

四、获取 API-KEY（两个大模型）

本工具使用两个大模型，各司其职：

模型平台用在哪个环节作用
qwen3.7-plus（通义千问视觉大模型）阿里云百炼第 4 步「图片 AI 解读」、公式图片识别理解图片内容，输出教材角度的图片解读（图片类型/内容理解/教学用途），识别公式图为 LaTeX
deepseek-v4-flash（DeepSeek 文本大模型）DeepSeek 开放平台第 5 步「教材文案生成」、学科自动判断把文本+公式+图片理解三份文档融合，生成每页 300 字以上教材口吻文案；判断课程/专业名称

① 阿里云百炼 API-KEY（qwen3.7-plus）

1
打开 https://www.qianwenai.com/（通义千问官网）→ 右上角「登录」，可用支付宝/淘宝账号快速登录；
2
进入后，若需开通 API 服务，按引导进入阿里云百炼（bailian.console.aliyun.com）→ 开通「百炼」模型服务；
3
在百炼控制台右上角头像 → 「API-KEY」→ 「创建新的 API-KEY」→ 复制保存（形如 sk-xxxxxxxx）；
4
新用户一般有免费额度；计费按 Token，具体以官网为准。

② DeepSeek API-KEY（deepseek-v4-flash）

1
打开 https://www.deepseek.com/ → 右上角「登录/注册」（支持手机号或邮箱）；
2
登录后进入「开放平台」（platform.deepseek.com）→ 左侧菜单「API Keys」→ 「创建 API Key」→ 复制保存；
3
DeepSeek 新用户通常赠送一定额度；按 Token 计费，价格透明。
设置环境变量（重要）：把两个 Key 写入系统环境变量（PowerShell 执行，需重开命令行生效）： 
setx DEEPSEEK_API_KEY "sk-你的DeepSeek密钥"
setx DASHSCOPE_API_KEY "sk-你的百炼密钥"
或者：右键「此电脑」→ 属性 → 高级系统设置 → 环境变量 → 新建用户变量。 也可以不手动设置：运行 pptx-paser 时会自动检查，缺失则打印注册引导并交互式输入、自动写入。

五、使用（快速开始）

# 一条命令跑完整流水线（自动装依赖 / 检查 Key / 预估 Token / 询问确认）
pptx-paser 第九章功率放大电路.pptx -o output

# 执行完成后，结果目录 output 下：
#   images/                教学图片集（PNG）
#   <名>_captions.md    图片理解文档
#   <名>_textbook.md    教材文案
#   <名>_binding.json   图文绑定

# 导出教材 HTML（浏览器打开即阅读，公式 MathJax 渲染）
pptx-html output -o output/第九章.html

# 导出教学 Deck（教育蓝图风格横版演示）
pptx-deck --dir output --template 模板路径 --out output/deck.html

# 分步执行与断点续跑
pptx-img 课件.pptx -o out                # 只看图片提取
pptx-formula 课件.pptx -o out            # 只提取公式
pptx-caption out/images -o cap.md --texts out/texts.md --formulas out/formulas.md
pptx-paser 课件.pptx -o out --skip img,formula,text   # 跳过已完成步骤续跑

六、应用场景

课程知识内容体系构建

对全部章节课件跑流水线，按 binding.json 聚合出「章→节→知识点→公式+配图」的知识树，直接用于课程大纲、资源包、知识图谱。

个性化学习内容生成

学生测验错题 → 知识点标签 → 检索对应教材文案/公式/图片 → 大模型融合学情生成个性化讲解与变式练习（基础版/进阶版）。

教材二次开发与多形态出版

以 textbook.md 为内容源重组章节，导出教材 HTML（网页/打印）、教学 Deck、Word/PDF；图片公式独立资产，支持双语与无障碍再加工。

智能问答与 RAG 检索

binding.json 作结构化索引：问题→检索相关页→图文并茂答案，自动标注「第 X 页、见下图」。

七、常见问题

  • 提示 No module named 'pythoncom'：cmd 所用 Python 缺 pywin32，执行 pip install pywin32；或直接用本工具自动安装。
  • 公式识别用大模型还是本地？：默认本地 pix2tex（零费用），质量不佳时可 --ocr-engine qwen 切大模型。
  • Token 消耗太多？：执行前会估算并确认；可用 --skip 跳过耗 Token 步骤，公式识别切本地。
  • WMF 矢量图浏览器打不开？：本工具已用 PowerPoint 自动渲染为 PNG 收录进 images/。
  • LibreOffice 没装？：公式路径 3 降级，OMML/EQ3 两路径不受影响。
