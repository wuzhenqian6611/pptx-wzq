摘要

Executive Summary

图块提取失败的根因**不在聚类算法，而在上游数据层**：组合形状（grpSp）被暴力拆散、组内坐标未变换，导致图块错位残缺；文本墙规则误伤叠加在图形上的文字；Visio 对象在原子对象阶段被静默丢弃。

🎯 定稿规则 16 条

识别层 1–9（组合即块、非组合按类型确定性处理）+ 解构解读层 10–16（XML 优先、DeepSeek 读 XML、qwen VLM 兜底）。

🔀 核心转变

流程重构：blocks 先行 → text/formula → AI 解读 → 过滤 → 扩写 → 绑定 → 输出；解读只按顺序读 sources/，images/ 仅供阅览；组内公式由 DeepSeek 转 LaTeX。

📦 交付物与生命周期

sources/（XML 段、.vsdx、矢量源、像素图原图）+ images/（渲染阅览图）+ JSON/MD 三件套；成功即清理过程文件，中断保留并自动接续。

v1.5.1 现状分析

As-Is Analysis

1.1 问题现象

现象说明
图块不完整用 PPT 自带工具（插入→组合/形状）画的图，只提取出图片部分，图块上方的文字（实为图块内容）未进图块。
文字变纯文本图块内文字被当作页面正文（textbook.md / texts.md 的纯文本条目），而非图块内容。
位置错乱组内元素坐标未叠加组合偏移，块 bbox 起点在页面左上角 (0,0)，与真实位置相差一个组合偏移。
Visio 静默丢失_collect_atomic_objects 无 visio 分支，Visio 记录在原子对象阶段被丢弃，不进任何块。

1.2 根因定位（代码级）

根因问题代码位置
AgrpSp 被暴力拆散、组内坐标未变换 extract_pptx_images._find_xfrm / _xfrm_xy 只取元素自身 <a:off>，未叠加组合偏移；iter_pictures / iter_native_shapes 用 root.iter() 递归把组内元素当顶层对象
B组内文字被当页面正文 extract_texts._iter_slide_texts 递归进 grpSp，图块标签文字被提取为 TXT 条目进入 textbook
C文本墙误伤叠图文字 visual_blocks.extract_blocks 用 max_shape_text=10 把超长文本框整体剔除，叠在图形上的大段说明文字全部丢失
Dcli_blocks 自举失效 + 过期提示 cli_blocks 缺 atomic_objects.json 时提示"请先运行 pptx-img"（该命令已下线）
E旋转组合逐元素变换复杂 组合可带 rot（如 60°），逐元素绝对坐标需旋转矩阵，易错 → 以"组合整体成块 + XML 段保留原生结构"规避
FVisio 记录不生成原子对象 _collect_atomic_objects 只有 picture/chart/formula 分支，缺 visio 分支；_emit_visio 产出的 kind="visio" 记录被静默丢弃
结论：1.5.1 对「组合绘制」的课件图块无效——坐标错位导致聚类错乱、组内文字散失、Visio 不进块。这恰好是 16 条规则要系统解决的。

定稿规则体系（16 条）

Rule Set

2.1 图块识别规则（1–9）

#规则一句话解读
1一个 grpSp 组合即是一个图块，组合内所有内容（文字/图片/公式/OLE）都是该图块内容组合 = 块的最高优先级容器，整体不可拆
2嵌套在另一个 grpSp 中的组合，不单独提取嵌套组合 = 外层图块的子结构
3OLE Visio/vsdx → 单独一个图块（除非在 grpSp 内）Visio 工程图本身即完整图块
4像素图若不在 grpSp 中 → 单独提取为一个图块每张位图独立可预期；重叠文字并入该块
5公式在 grpSp 中 → 块内容；否则单独提取为公式公式归属由"是否在组合内"决定
6第一页（题目页）与最后一页（致谢页）图块/像素图舍弃封面封底不产图块；文本/公式仍提取
7非 grpSp 像素图面积 < 整页 20% → 舍弃小装饰图标不进块
8表格在 text 文本提取阶段按表格读取，输出 Markdown 表格文本（不参与图块生成）texts.md 输出 Markdown 表格；组合内表格随 XML 段保留
9grpSp 内 srcRect（图片裁剪显示区域）处理须保留一致元数据/资源/渲染/描述全程一致

识别优先级：grpSp > Visio > 像素图（≥20%）> 矢量（SVG/WMF）——blocks 只产确定性图块（无自由聚类）；shape/connector 不单独成块（文本走 text 阶段、箭头随组合或忽略）；表格移交 text 阶段；公式不参与块；首页/尾页整页跳过。

2.2 图块解构与解读规则（10–16）

#规则一句话解读
10grpSp 组合块保留整个组合 XML 代码段，页面序号标记；每组合一个独立 *.xml 文件存 sources/组合的源语言表达，一组合一文件
11grpSp 块 caption 用 DeepSeek-V4-Flash 直接读 XML 段；组内公式 → DeepSeek 转 LaTeX 融入 caption文本模型读 XML，公式转 LaTeX
12grpSp 块解构调用 PowerPoint 渲染 PNG 存 images/；caption 不把 PNG 送 qwen3.7-plus渲染产物 ≠ 解读输入
13Visio/vsdx 可剥离 → .vsdx 存 sources/ + 渲染 PNG 存 images/可编辑原生源 + 可视渲染双产物
14Visio 不可剥离 → 存 XML 代码段，处理与 grpSp 一致退化路径：XML 兜底
15SVG/WMF 等矢量 → 同 Visio：尽量 XML 段，不行才 PNG矢量优先 XML，栅格化兜底
16只有无法用 DeepSeek 解读 XML 的块（纯像素图）才送 qwen3.7-plus VLM解读模型按块路由，VLM 兜底
解读通道路由：grpSp / Visio-XML / SVG-WMF 矢量 → DeepSeek-V4-Flash（读 XML 段，公式转 LaTeX）；纯像素图 / 无 XML 可读的块 → qwen3.7-plus（读 PNG）。
公式归宿（规则 5，四环节接力）：组合内公式不进入 formula 步骤的输出——① blocks 随组合保留原始 <m:oMath> XML（在 grpSp XML 段内）→ ③ formula 识别祖先 grpSp 标记 in_group、从 formulas.md 排除 → ④ caption DeepSeek 读 XML 段时转 LaTeX 融入块 caption → ⑥ author 扩写消费。归宿唯一：组合内 → 块 caption（LaTeX）；组合外 → formulas.md。

文件Schema内容与格式

v1.5.1 vs v2.0.0 对比

Comparison

v1.5.1（现状）

  • 流程：text → formula → blocks → related → author → blocks_json
  • grpSp 被拆散，组内元素坐标错位
  • 组内文字进页面正文纯文本
  • >10 字文本框整块剔除（文本墙）
  • Visio 无原子对象分支 → 静默丢失
  • caption 全部走 qwen VLM 看 PNG
  • 块内公式仅文本，不转 LaTeX
  • 渲染依赖 LibreOffice；过程文件常驻
  • 无 XML 段交付；像素图资源不在 sources/
→

v2.0.0（重构）

  • 流程：blocks → text/formula → caption → related → author → binding → 输出
  • grpSp → group 块，bbox 正确，children 收编
  • 组内文字 → 块内容（[图块内文本]）
  • 文本墙例外：与图形重叠的文本放行
  • 新增 visio 分支：独立块 / 剥离 vsdx / XML 兜底
  • 解读按 sources/ 顺序：DeepSeek 读 XML；qwen 仅像素图兜底
  • 组内公式 → DeepSeek 转 LaTeX 融入 caption
  • PowerPoint 渲染优先；成功清理过程文件、中断自动接续
  • sources/ 每组合一个 XML 段文件 + 像素图原图
  • blocks 单阶段确定性拆块（无自由聚类）；表格移交 text 阶段输出 Markdown
